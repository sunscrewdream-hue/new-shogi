# 完成版9×9と幕末物語の基本システム照合（2026-11-07）

## 照合の基準

- 正本：`card-ai-test.html` ＋ 実行時に適用される `enhancements.js`。HTML単体の関数だけを正本とはみなさない。
- 物語：`story-engine.js` ＋ `story-mode.js`。池田屋／禁門の変／油小路／鳥羽・伏見の全4章。
- 章専用の盤サイズ、史実、背景、BGM、鳥羽・伏見の専用兵器は許容差異。ただし将棋の合法手、捕獲・覚醒・事件札の効果を変更する差異は要確認。
- 過去の根拠：`docs/STORY_PARITY_HANDOFF_2026-11-05.md`。最新の実装・ユーザー指示との食い違いは自動的に正当化しない。

## 実測した共通部分

`node tests/story-finished-legal-parity.test.cjs` で、**禁門の変と鳥羽・伏見の9×9局面660件（手番双方）**について、完成版に実際に適用される `enhancements.js` の「主君を見捨てる」ルールまで含めて合法手集合を照合した。**全660件一致**。

同じテストは初期局面だけでなく、捕獲・成りを伴うランダムな対局途中の局面を使う。5×6には完成版と同じ盤サイズの対照がないため、この一致を5×6に外挿しない。

`node tests/story-random-play.test.cjs` では物語全4章の20局・1,608手を確認。捕獲233回、斬殺27回、王手136回を含み、駒の一意性・盤面範囲・持ち駒の基本不変条件を満たした。

## 実装統合の提案

1. **完成版のルールを基準**に、共通の合法手・捕獲・覚醒・事件札「効果判定」をゲームロジック層にまとめる。すでに正しく動く描画・音声・画像処理は移植せず維持する。
2. `story-engine.js` は盤サイズと章設定のアダプターに絞る。5×6も同一規則で判定できるようにする。
3. 鳥羽・伏見の兵器、章固有のカード構成・AI難度・演出は明示的な設定項目で宣言し、ゲームロジック内の章番号分岐を減らす。
4. 同一局面・同一行動に対して、完成版と物語で「合法手・捕獲結果・手番・勝敗・事件札の効果」が一致する回帰テストを継続追加する。

**この監査では仕様に判断を要するゲームロジックの差異は変更していない。** ユーザーと統一仕様を確認してから、1分野ずつテスト付きで実装を収束させる。
