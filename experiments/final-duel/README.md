# 最後の一発｜独立検証版

このフォルダは **GitHub開発テスト専用**です。既存の通常版・物語・二人対戦のゲーム本編にはまだ接続していません。Googleドライブの正式正本や `main` は変更しません。

## 起動
`index.html` を静的HTTPサーバーで開く。リポジトリのブランチは `experiment/final-duel-pistol-20261113` です。GitHubのコード表示画面はゲーム実行画面ではありません。

## 検証できること
- 9×9と5×6の王将2枚だけの局面
- 二人対戦または簡易CPU戦
- 空きマスで、双方の王将から合法的に到達できる位置のみ拳銃を出現
- 到達予定手数と手番を考慮して、近い候補からランダム選定
- 王将で拳銃マスを拾えば即決着。いずれの陣営も同一の処理
- 4半手ごとに未取得の拳銃を再配置
- ブラウザ画面の「検査を実行」で全王将配置の候補検査
- `node --test experiments/final-duel/final-duel.test.cjs` で自動回帰検査

## 現状の制約
- 銃画像は **S&W No.2 Army の実物写真**を外部参照。画像は [Wikimedia Commons: Smith & Wesson Army No 2.JPG](https://commons.wikimedia.org/wiki/File:Smith_%26_Wesson_Army_No_2.JPG)。画像の改変・再配布時は原典の著作者・ライセンスを確認する（本試作では画像のローカル配布なし）。画像読み込み失敗時は絵文字にフォールバック。
- 支給動画の「これで仕舞いだ！」から切り出し・音量調整した `voice_koredeshimaida.mp3` を **GitHubブランチに実際に収録**し、取得時と「音声・発砲テスト」ボタンから再生。
- 拳銃の発砲音は Web Audio による簡易合成音。本番用効果音は未採用。
- CPUは到達距離に基づく **簡易実験AI**。本編のAI・勝利画面・音量設定・セーブ／ロードは未接続
- 到達判定は現時点の相手王将位置を固定した合法経路に基づく。実際の動的な王将の駆け引き・完全な公平性は本番統合前に実プレイ評価が必要
- 既存本編へ統合する際は正本の現行ソースを再取得し、`shared-final-duel.js` 型の共通処理を一度だけ実装して各モードから呼び出すこと。古い GitHub 内の本編コードで正式版を置き換えない
